# Personal Portfolio & Blog Application

## Overview

This project is a responsive personal portfolio and blog application built using HTML, TailwindCSS, and Express.js. The application was designed in Figma and then implemented as a static frontend to prepare for future React component integration in Module 8.

The portfolio showcases:
- Personal introduction
- Skills and services
- Portfolio projects
- Contact form
- Blog structure
- Admin dashboard layout

The application was built with a strong focus on responsive design, clean UI/UX, and reusable component structure.

# Design Process

The project design process began in Figma where wireframes and high-fidelity mockups were created for each page. The design uses:
- A dark modern UI theme
- Orange accent colors
- Responsive layouts
- Card-based sections
- Consistent typography and spacing

The frontend was then implemented using TailwindCSS utility classes to closely match the original Figma design while maintaining responsiveness across devices.

---

# Responsive Design

The application was designed to work across:
- Mobile devices
- Tablets
- Desktop screens

TailwindCSS responsive utility classes were used throughout the project to ensure adaptability and consistency across screen sizes.
